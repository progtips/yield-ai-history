# Контекст для Cursor AI - Yield AI Project

## 🎯 Основная цель проекта

**Yield AI** - это DeFi инвестиционная панель на блокчейне Aptos, которая объединяет множественные протоколы в едином интерфейсе для упрощения yield farming.

### Ключевые проблемы, которые решает проект:
1. **Фрагментация DeFi** - пользователям сложно отслеживать позиции в разных протоколах
2. **Сложность входа** - новичкам трудно начать yield farming
3. **Отсутствие сравнения** - нет единого места для сравнения доходности
4. **Сложность управления** - трудности в управлении множественными позициями

## 🏗️ Архитектурные принципы

### 1. Модульность
- Каждый протокол изолирован в отдельном модуле
- Общие интерфейсы через `BaseProtocol`
- Переиспользуемые UI компоненты

### 2. Пользовательский опыт
- Единый интерфейс для всех протоколов
- Drag & Drop для интуитивного управления
- AI-ассистент для помощи пользователям

### 3. Безопасность
- Локальное подписание транзакций
- Никакого хранения приватных ключей
- Интеграция только с проверенными протоколами

## 📁 Ключевые файлы и их назначение

### Основные компоненты
- `src/app/dashboard/page.tsx` - Главная страница с инвестиционными возможностями
- `src/components/portfolio/` - Компоненты для отображения портфеля
- `src/components/protocols/` - Компоненты для каждого протокола
- `src/lib/protocols/` - Логика интеграции с протоколами
- `src/lib/services/` - API сервисы для внешних данных

### API Endpoints
- `src/app/api/aptos/` - Интеграция с блокчейном Aptos
- `src/app/api/panora/` - Интеграция с DEX Panora
- `src/app/api/protocols/` - API для каждого протокола

### State Management
- `src/lib/stores/` - Zustand stores для глобального состояния
- `src/contexts/` - React Context для тематических данных

## 🔌 Поддерживаемые протоколы

### Lending Protocols (Кредитные протоколы)
1. **Echelon** - Нативная интеграция, депозиты и управление позициями
2. **Joule** - Нативная интеграция, депозиты и управление позициями  
3. **Aries** - Внешняя интеграция, только отслеживание позиций

### DEX Protocols (Децентрализованные биржи)
1. **Hyperion** - Нативная интеграция, свопы и управление позициями
2. **Tapp** - Внешняя интеграция, только отслеживание позиций

## 📋 Инструкции для Cursor AI

### При добавлении новых функций:

1. **Анализируйте контекст**:
   - Как функция вписывается в общую архитектуру?
   - Какие протоколы затрагивает?
   - Нужны ли новые API endpoints?

2. **Следуйте паттернам**:
   - Используйте существующие компоненты из `src/components/ui/`
   - Наследуйтесь от `BaseProtocol` для новых протоколов
   - Используйте типизацию TypeScript

3. **Учитывайте пользовательский опыт**:
   - Функция должна быть простой в использовании
   - Обеспечьте понятную обратную связь
   - Обрабатывайте ошибки gracefully

4. **Безопасность**:
   - Никогда не храните приватные ключи
   - Валидируйте все входные данные
   - Используйте безопасные API вызовы

### При работе с протоколами:

1. **Нативная интеграция** (Echelon, Joule, Hyperion):
   - Создайте класс протокола в `src/lib/protocols/`
   - Добавьте API endpoints в `src/app/api/protocols/`
   - Создайте UI компоненты в `src/components/protocols/`

2. **Внешняя интеграция** (Aries, Tapp):
   - Только отслеживание позиций
   - Редирект на внешний сайт для действий
   - Парсинг данных с внешних API

### При работе с UI:

1. **Компоненты**:
   - Используйте shadcn/ui компоненты
   - Следуйте существующим паттернам
   - Обеспечьте responsive дизайн

2. **Состояние**:
   - Используйте Zustand для глобального состояния
   - React Context для тематических данных
   - Local state для компонент-специфичных данных

3. **Стили**:
   - Используйте Tailwind CSS классы
   - Следуйте существующей цветовой схеме
   - Обеспечьте accessibility

## 🚀 Частые задачи и их решения

### Добавление нового протокола:
1. Создать класс протокола в `src/lib/protocols/`
2. Добавить в `src/lib/data/protocolsList.json`
3. Создать API endpoints в `src/app/api/protocols/`
4. Создать UI компоненты в `src/components/protocols/`
5. Обновить dashboard для включения нового протокола

### Добавление новой функции:
1. Определить, где она должна быть размещена
2. Создать необходимые API endpoints
3. Создать UI компоненты
4. Обновить типы в `src/types/`
5. Добавить тесты

### Оптимизация производительности:
1. Использовать React.memo для тяжелых компонентов
2. Реализовать lazy loading для больших списков
3. Кэшировать API ответы
4. Оптимизировать bundle size
