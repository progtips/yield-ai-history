# Архитектура проекта Yield AI

## 🎯 Общая цель проекта

**Yield AI** - это комплексная DeFi инвестиционная панель на блокчейне Aptos, которая решает следующие ключевые проблемы:

1. **Фрагментация DeFi**: Пользователям сложно отслеживать позиции в разных протоколах
2. **Сложность входа**: Новичкам трудно начать yield farming
3. **Отсутствие сравнения**: Нет единого места для сравнения доходности
4. **Сложность управления**: Трудности в управлении множественными позициями

## 🏗️ Архитектурные принципы

### 1. Модульность

- Каждый протокол изолирован в отдельном модуле
- Общие интерфейсы через `BaseProtocol`
- Переиспользуемые UI компоненты

### 2. Расширяемость

- Легкое добавление новых протоколов
- Плагинная архитектура для новых функций
- Гибкая система API endpoints

### 3. Пользовательский опыт

- Единый интерфейс для всех протоколов
- Drag & Drop для интуитивного управления
- AI-ассистент для помощи пользователям

### 4. Безопасность

- Локальное подписание транзакций
- Никакого хранения приватных ключей
- Интеграция только с проверенными протоколами

## 📁 Структура проекта

```
src/
├── app/                          # Next.js App Router
│   ├── api/                     # API endpoints
│   │   ├── aptos/              # Aptos blockchain API
│   │   ├── panora/             # Panora DEX API
│   │   └── protocols/          # Protocol-specific APIs
│   ├── dashboard/              # Main dashboard page
│   └── test-*/                 # Test pages for development
├── components/                  # React components
│   ├── ui/                     # Reusable UI components (shadcn/ui)
│   ├── portfolio/              # Portfolio management
│   ├── protocols/              # Protocol-specific components
│   └── WalletConnect.tsx       # Wallet integration
├── lib/                        # Core business logic
│   ├── protocols/              # Protocol implementations
│   ├── services/               # External API services
│   ├── stores/                 # State management (Zustand)
│   └── utils/                  # Utility functions
└── types/                      # TypeScript definitions
```

## 🔄 Потоки данных

### 1. Подключение кошелька

```
Wallet Connect → Aptos SDK → Wallet Store → Portfolio Load
```

### 2. Загрузка инвестиционных возможностей

```
Protocol APIs → Pools Service → Dashboard → UI Components
```

### 3. Выполнение депозита

```
User Action → Protocol Class → Transaction Builder → Wallet Sign → Blockchain
```

### 4. Отслеживание позиций

```
Blockchain → Protocol APIs → Position Store → UI Updates
```

### 3. Простота

## 🔌 Интеграции

### Поддерживаемые протоколы

1. **Echelon** - Lending (нативная интеграция)
2. **Joule** - Lending (нативная интеграция)
3. **Aries** - Lending (внешняя интеграция)
4. **Hyperion** - DEX (нативная интеграция)
5. **Tapp** - DEX (внешняя интеграция)

### Внешние API

- **Panora** - Цены токенов и свопы
- **Aptos** - Блокчейн данные
- **Gas Station** - Комиссии за транзакции

## 🛠️ Технические решения

### Frontend

- **Next.js 15** - для SSR и оптимизации
- **TypeScript** - для типобезопасности
- **Tailwind CSS** - для быстрой стилизации
- **shadcn/ui** - для консистентного UI

### State Management

- **Zustand** - для глобального состояния
- **React Context** - для тематических данных
- **Local Storage** - для персистентности

### Blockchain

- **Aptos SDK** - для взаимодействия с блокчейном
- **Wallet Adapter** - для мульти-кошельковой поддержки
- **BCS** - для сериализации транзакций
